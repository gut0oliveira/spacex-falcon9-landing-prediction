## Sobre o repositório

Este repositório reúne projetos desenvolvidos para aplicar diferentes etapas do ciclo de **Ciência de Dados**, desde a coleta e preparação dos dados até a análise exploratória, visualização e construção de modelos de Machine Learning.

Os projetos têm como objetivo aplicar técnicas e ferramentas de Ciência de Dados na resolução de problemas analíticos e preditivos.

## Projetos

### 🚀 SpaceX Falcon 9 — IBM Applied Data Science Capstone

Projeto desenvolvido como parte do **IBM Data Science Professional Certificate**, aplicando um pipeline completo de Ciência de Dados sobre lançamentos do foguete **Falcon 9, da SpaceX**.

O objetivo do projeto é analisar dados históricos de lançamentos e desenvolver modelos capazes de prever o sucesso do pouso do primeiro estágio do Falcon 9.

A reutilização do primeiro estágio é um dos principais fatores responsáveis pela redução dos custos de lançamento da SpaceX, tornando sua previsão um problema relevante para análise.

### Etapas do projeto

#### 1. Coleta de Dados

- Extração de dados utilizando API
- Web Scraping
- Construção e organização dos datasets

#### 2. Data Wrangling

- Limpeza e transformação dos dados
- Tratamento de valores e variáveis
- Preparação dos dados para análise

#### 3. Análise Exploratória de Dados

- Exploratory Data Analysis (EDA)
- Análises utilizando Pandas
- Visualizações com Matplotlib e Seaborn
- Consultas e análises utilizando SQL

#### 4. Análise Visual e Dashboards

- Visualização interativa dos lançamentos
- Análise geográfica dos locais de lançamento
- Construção de dashboard utilizando Plotly Dash

#### 5. Machine Learning

- Preparação dos dados para modelagem
- Treinamento de modelos de classificação
- Comparação de algoritmos
- Avaliação de desempenho
- Previsão do sucesso do pouso do primeiro estágio

**Tecnologias:** `Python` `Pandas` `NumPy` `SQL` `Matplotlib` `Seaborn` `Plotly` `Dash` `Scikit-learn` `Jupyter Notebook`
